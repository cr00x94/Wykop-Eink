## About

**Wykop EInk** is an unofficial Android client for [Wykop.pl](https://wykop.pl), designed specifically for devices equipped with E Ink displays.

The application focuses on readability, simplicity, and a distraction-free experience. Its interface is optimized for monochrome e-paper screens, making browsing community content and reading articles more comfortable.

Unlike traditional mobile applications, Wykop EInk prioritizes text and minimizes unnecessary visual elements.

## Features

### Content browsing
- Browse Wykop.pl discoveries (Znaleziska).
- Explore Microblog posts.
- Search for content.
- View saved posts.
- Refresh content using a dedicated control.

### E Ink optimization
- High-contrast monochrome interface.
- Minimalist layout.
- Adjustable font size.
- Reduced visual clutter.
- Readability-focused design.

### Article reading
- Open articles inside the application or in the system browser.
- Dedicated simple reading mode.
- Remove images, buttons, links, and other distracting page elements in simple mode.
- Optimized reading experience for e-paper screens.

### Personalization
- Block unwanted tags.
- Block unwanted domains.
- Mark viewed articles.
- Hide read articles.
- Toggle discovery descriptions.
- Configure article display behavior.

### Privacy-oriented features
- Automatic handling of cookie consent dialogs.
- Attempts to reject optional cookies rather than accepting all.
- No unnecessary visual distractions.

## Installation

### Download APK

1. Open the [Releases](../../releases) section.
2. Download the latest APK.
3. Enable installation from unknown sources if required by your Android device.
4. Install the APK.

> This project is currently in beta. Compatibility may vary depending on the Android version and E Ink device.

## Technology Stack

- **Kotlin** – primary programming language.
- **Jetpack Compose** – declarative UI framework.
- **Retrofit** – API communication.
- **OkHttp** – HTTP client.
- **Gson** – JSON serialization and deserialization.
- **Android WebView** – embedded article reading.
